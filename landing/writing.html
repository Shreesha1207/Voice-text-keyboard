How it works

Four steps, and it never guesses what you meant.

The Writing engine is deliberately unhurried about touching your machine. It does not watch your selections, it does not read your screen, and it does not put anything on your clipboard until you have clicked a button that says it will.

Step one

Select, then right-click

Right-click is the single entry point. It shows the floating Xvoice button and does nothing else — no copy, no read, no network call.

Step two

Click the button

Only now is your selection copied. A click means press and release on the button, so a drag that happens to end there is not a click and will not fire.

Step three

Pick an action and a tone

Six actions in the menu, five tones underneath, and a Translate submenu for your saved languages. Your defaults come pre-selected.

Step four

Preview, then accept

The rewrite appears in a floating panel beside the cursor with Accept and Dismiss, and closes itself after 12 seconds if you ignore it. Or set it to replace immediately.

Focus

It puts the text back where you were

Accepting restores focus to the editor you were in before it pastes. Without that step the rewrite lands in whatever window happened to be in front — which is the classic way this kind of tool ruins a document.

Terminals

It knows not to send Ctrl+C to a console

In an editor Ctrl+C copies. In a terminal it is SIGINT, and with nothing selected it kills whatever is running. Xvoice recognises Windows console windows and refuses to send that keystroke there.

Linux

It tells you when the clipboard is missing

On Linux the clipboard needs xclip or xsel. Xvoice checks once at startup and says so plainly, rather than silently doing nothing forever.

Actions

Ten things it will do to a paragraph.

Six are in the desktop menu because those are the six that get used. All ten are on the API, so the dashboard and any future client can reach them. Whichever you pick, formatting survives: line breaks, punctuation, emojis, numbering and bullet lists come back intact, and you get the transformed text and nothing else — no preamble, no summary of what changed.

Your defaults

Set it once. It follows you to every machine.

Preferences live on your account, not in a config file on one computer. Change them on the dashboard and the desktop app picks them up — no restart, no re-login.

Default action

The one you reach for

Pre-selected in the menu. Ships as Improve writing.

Default tone

Applied unless you change it

One of the five. Ships as Neutral, meaning no tonal instruction is added at all.

Default language

Where Translate goes

Used when you pick Translate without choosing a target. Ships as English.

Preview or replace

How the result arrives

Preview with Accept/Dismiss is the default. Turn on auto-replace and the selection is swapped the moment the rewrite comes back.

Writing hotkey

Separate from dictation

Right-click by default. Or bind F2–F12, Ctrl, Alt, Shift, Space, Tab, Caps Lock, Esc, Enter, the arrows, Insert, Delete, Home, End or Page Up/Down — validated server-side so the desktop app can never be handed a key that breaks it.

Privacy & safety

It reads what you highlight, and nothing else.

Consent

Nothing is copied until you click

Selecting text does not trigger anything. Right-clicking only offers the button. Your clipboard is read at the moment you click it, and not before.

Retention

Only a 200-character excerpt is stored

The history view renders a 120-character snippet, so that is all that needs keeping. Everything you highlight is not archived in full, forever.

Logs

Your text is never written to the log file

Logs record lengths, action names and status codes. Not the text you rewrote, and not what came back.

Prompt injection

Your text is data, never instructions

Every action tells the model to treat the input strictly as text to transform, and never to execute, answer, obey or act on anything inside it. A pasted email full of “ignore your instructions” gets rewritten, not obeyed — which matters, because the text you highlight usually came from somebody else.

No API keys

The model key is never on your machine

Rewrites run on the Xvoice backend, which holds the OpenAI key server-side. You sign in through your browser once and the desktop app never sees it.

Sessions

Log out everywhere, instantly

One click invalidates every token on every device at once, desktop and browser, by bumping a version the server checks on each request.

Questions

Before you download

Do I have to buy Dictation to use Writing?

No. Writing is sold on its own and resolved independently. If you already have Dictation Pro you get 100 writing actions a month included, but that is a taste of the product, not a substitute for it.

Which applications does it work in?

Any application where you can select text and copy it — browsers, Word, Slack, email clients, code editors, note apps, PDF readers with selectable text. The rewrite is pasted back the same way, so anywhere you can paste, it can write.

Does it watch everything I select?

No, and this is deliberate. Selecting text does nothing at all. Right-clicking only makes the button appear. Your selection is copied at the moment you click that button, and never before it.

What if I do not like the rewrite?

Dismiss it and nothing changes — the preview panel closes on its own after 12 seconds if you ignore it. Your original text is untouched until you press Accept. If you would rather skip the step entirely, auto-replace is a setting.

How long can the selection be?

8,000 characters, roughly 1,200 words. Anything longer is rejected before a model call is made, so it does not silently eat one of your monthly actions.

Does it keep my text?

Only a 200-character excerpt of the input and output, because the history view renders a 120-character snippet. Nothing you rewrite is written to the log file — logs record lengths, action names and status codes.

Can I add a language that is not in the menu?

Yes. Six are built in; 54 more are on the settings page and you can pin up to twelve into the Translate submenu at a time.

Can I trigger it with a key instead of right-clicking?

Yes, and it is a separate hotkey from dictation, so the two never collide. Pick a function key or a standard modifier; the allowed set is validated server-side so the desktop app can never be handed a binding that breaks it.

It does nothing on my Linux machine.

The clipboard needs xclip or xsel installed. Xvoice checks at startup and logs the exact fix — sudo apt install xclip.

What happens when my trial ends?

Writing drops to the free allowance of 30 actions a month. Nothing is deleted, your preferences and pinned languages stay, and your Dictation trial is unaffected because it runs on its own clock.

Fourteen days free, on its own clock. No API key, no configuration, and no second app to install — it is in the one you already downloaded.
